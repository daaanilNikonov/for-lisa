# Лендинг с тестом «1С:Кабинет сотрудника»

Фирменный стиль ГК Форус (бело-жёлтый, логотип). 7 вопросов → **10 сценариев по триггерам**.

## Открыть

- Файл `ОТКРЫТЬ ЛЕНДИНГ.html` или `index.html`
- Секция `#editor` — окно загрузки картинки + текста для каждого сценария

```bash
cd "лендинг тест"
python3 -m http.server 8080
```

## Файлы

| Файл | Назначение |
|------|------------|
| `scripts-data.js` | Вопросы + 10 сценариев и правила триггеров |
| `SCRIPTS.md` | Описание каналов |
| `assets/brand/logo-forus.png` | Логотип форус |
| `assets/results/temp-*.jpeg` | Временные 3 картинки |
| `ССЫЛКА.md` | Ссылки на папку и превью |
