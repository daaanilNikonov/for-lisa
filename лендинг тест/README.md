# Лендинг с тестом «1С:Кабинет сотрудника»

Интерактивный лендинг: 7 вопросов из брифа, результат по каналу **должность × численность** (30 скриптов).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
cd landing
python3 -m http.server 8080
```

Затем откройте http://localhost:8080

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка лендинга и теста |
| `styles.css` | Стили |
| `app.js` | Логика теста и показа результата |
| `scripts-data.js` | Вопросы + 30 скриптов с плейсхолдерами |
| `SCRIPTS.md` | Таблица всех каналов для согласования |
| `assets/results/` | Слоты под итоговые картинки |

## Логика

1. Пользователь отвечает на все 7 вопросов.
2. Канал результата = `role + size` (вопросы 1 и 2).
3. На экране результата:
   - поле **«Здесь будет текст»**
   - поле **«Здесь будет картинка»** (путь слота)
   - профиль ответов 3–7 для дальнейшей доработки контента
4. Внизу страницы — сетка всех 30 скриптов с плейсхолдерами.
