# 10 сценариев теста (триггеры)

Канал результата больше **не** считается как «должность × численность» (30 картинок).

Теперь **10 сценариев** по триггерам. Численность персонала на выбор картинки **не влияет**.

## Триггеры напряжения → авральные сценарии

| Ответ | Триггер |
|-------|---------|
| обращаются ежедневно | напряжение |
| почти всегда (задержки) | напряжение |
| в последний день (отчётность) | напряжение |

## Триггеры спокойствия → «детокс» / цифра

| Ответ | Триггер |
|-------|---------|
| более 80% автоматизировано | спокойствие |
| есть КЭДО | спокойствие |
| сразу (отчётность) | спокойствие |
| очень редко / не обращаются | спокойствие |
