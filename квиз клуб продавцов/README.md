# Квиз «Клуб продавцов» — отработка возражений

Формат **«100 к 1» / Своя игра** по файлу [`Игра клуб продавцов.docx`](../Игра%20клуб%20продавцов.docx).

## Файл

[`Квиз_Клуб_продавцов_Отработка_возражений.pptx`](./Квиз_Клуб_продавцов_Отработка_возражений.pptx)

## Механика

1. Титул → **игровое поле** (5 тем × баллы 10 / 30 / 50 / 70 / 100 / 150)
2. Клик по ячейке → слайд с **кейсом** (ситуация + возражение + задача команде)
3. **Таймер на обдумывание** (из правил файла):
   - 10 / 30 / 50 → **1,5 минуты** (90 сек)
   - 70 / 100 → **2 минуты** (120 сек)
   - 150 → **3 минуты** (180 сек)
4. После таймера автоматически появляется **ключ для ведущего**
5. «← К полю» — назад; открытые ячейки краснеют (followed hyperlink)

## Темы

| Тема | О чём кейсы |
|------|-------------|
| Цена и бюджет | Дорого, бюджет на железо, дешевле у конкурента, оплата после go-live, ROI, гарантия окупаемости |
| Не сейчас / подумаем | КП на почту, сезон, тишина после демо, «после проверки», бесплатный аудит, старт через 9 месяцев |
| Уже есть / конкурент | Excel, только БП, Битрикс за 2 недели, только лицензии, «свой» подрядчик, провал прошлого 1С |
| Риски и доверие | Облако упадёт, ПДн, ИБ-доработки, «локальный подрядчик», бесплатный пилот, безлимитная ответственность |
| ЛПР и политика | Согласования, нет доступа к директору, IT против, конфликт фин/IT, тендер по цене, спонсор уволился |

Два однотипных и один «красный» кейс из исходного файла заменены:
- вместо «скиньте 30% на тендере» — чужие/серые лицензии + ваша ответственность;
- вместо «заморозьте до конца года» — пауза из‑за M&A + бесплатный due diligence;
- вместо «ИБ не пропустит без доработок в КП» — требование пентеста за счёт подрядчика до сделки.

Во всех кейсах: название компании, ЛПР и развёрнутая ситуация.
