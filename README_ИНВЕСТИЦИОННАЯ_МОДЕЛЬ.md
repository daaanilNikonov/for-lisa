# Инвестиционная модель «1С:Кабинет сотрудника»

Файл: [`Финансовый_план_Кабинет_сотрудника_ИНВЕСТИЦИОННАЯ_МОДЕЛЬ.xlsx`](./Финансовый_план_Кабинет_сотрудника_ИНВЕСТИЦИОННАЯ_МОДЕЛЬ.xlsx)

## Как пользоваться

1. Откройте лист **00_Инструкция** — легенда цветов и порядок работы.
2. Все параметры меняйте только на **01_Исходные_данные** (зелёные ячейки).
3. Факт продаж вносите на **08_Факт_воронка** — обновятся P&L, ДДС и Dashboard.
4. Для защиты проекта смотрите **11_Dashboard** и **03_TAM_SAM_SOM**.

| Цвет | Смысл |
|------|--------|
| Зелёный | Ввод |
| Серый | Формула |
| Красный | Контрольный KPI |

## Структура листов

| Лист | Назначение |
|------|------------|
| 00_Инструкция | Руководство |
| 11_Dashboard | Сводка для инвестора |
| 01_Исходные_данные | Единая точка ввода |
| 02_Тарифы | Прайс пакетов |
| 03_TAM_SAM_SOM | Рынок |
| 04_Сегменты_базы | ОКВЭД / 22+ / пересечение |
| 05_База_клиентов | Полная база + обогащение |
| 06_Горячие_клиенты | Работа менеджеров |
| 07_План_продаж | Сценарии 4/6/9 и источники |
| 08_Факт_воронка | Факт: обработка→…→оплата |
| 09_PnL | Прибыли и убытки |
| 10_ДДС | Денежный поток и безубыточность |
| 12_Методика | Источники и правила |

## Обогащение данных

- **ССЧР**: открытые данные ФНС (`7707329152-sshr2019`, 2025).
- **ОКВЭД**: выписки ЕГРЮЛ для компаний с численностью 22+.
- Сырые индексы лежат в `data/`.
