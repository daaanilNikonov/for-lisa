# Инвестиционная модель «1С:Кабинет сотрудника»

Файл: [`Финансовый_план_Кабинет_сотрудника_ИНВЕСТИЦИОННАЯ_МОДЕЛЬ.xlsx`](./Финансовый_план_Кабинет_сотрудника_ИНВЕСТИЦИОННАЯ_МОДЕЛЬ.xlsx)

## Коммерческое предложение

**Пилот:** 10 кабинетов для подключения КЭДО с последующим расширением — **3 360 ₽/год** (закупка 1 680 ₽, маржа 1 680 ₽).

Эта сумма используется в плане, прогнозе, P&L и ДДС.

## План продаж менеджера

| Сценарий | План оплат / мес |
|----------|------------------|
| Малый | 3 |
| Средний | 5 |
| Перевыполнение | 7 |

На листе **07_План_продаж** видно:
1. сколько клиентов в сегментах базы;
2. сколько нужно **обработать** при плановых конверсиях, чтобы выполнить план;
3. обратную воронку (оплаты ← сделки ← демо ← переговоры ← обработка);
4. **прогноз ≥ план** (контроль OK/МАЛО);
5. экономику команды при КП 3 360 ₽.

## Как пользоваться

1. `01_Исходные_данные` — единственная точка ввода (зелёные ячейки).
2. `08_Факт_воронка` — фактические этапы.
3. `11_Dashboard` — сводка для защиты.

| Цвет | Смысл |
|------|--------|
| Зелёный | Ввод |
| Серый | Формула |
| Красный | Контрольный KPI |
