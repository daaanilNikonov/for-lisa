## Как играть (.pptm)

1. Откройте **`.pptm`** в PowerPoint (разрешите макросы).
2. Титульный слайд → **игровое поле** (5 тем × 10 / 30 / 50 / 70 / 100).
3. Клик по ячейке → макрос красит **заливку** в красный (`#C0392B`) и открывает вопрос.
4. На слайде вопроса — **таймер 30 секунд**; ответ появляется автоматически через 30 секунд.
5. **«← К полю»** возвращает на поле; открытые ячейки остаются красными.

## Пересборка

```bash
python3 scripts/build_epd_quiz.py
```

Для сборки `.pptm` нужны `aspose-slides`, `libssl1.1` и `libgdiplus` (генерируется `vbaProject.bin`). Если Aspose недоступен, используется кэш `vbaProject.bin` в этой папке.
