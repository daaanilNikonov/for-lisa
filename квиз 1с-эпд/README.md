# Квиз «1С-ЭПД / Доки.Логистика» — формат 100 к 1

Интерактивная презентация в корпоративном стиле ГК Форус (тёмный шаблон).

## Файл

[`Квиз_1С-ЭПД_Доки_Логистика_100к1.pptx`](./Квиз_1С-ЭПД_Доки_Логистика_100к1.pptx)

Источник вопросов: [`своя игра эпд.docx`](./своя%20игра%20эпд.docx)

## Как играть

1. Титульный слайд — название квиза  
2. **Игровое поле** — 5 тем × баллы 10 / 30 / 50 / 70 / 100  
3. Клик по ячейке с баллами → слайд с вопросом (гиперссылка)  
4. Открытые ячейки на поле **краснеют** (номер становится красным после возврата)
5. На слайде вопроса — **таймер 30 секунд** (анимированный)
5. **Ответ появляется автоматически через 30 секунд**
6. Кнопка **«← К полю»** возвращает на игровое поле  

Открывать в PowerPoint / LibreOffice Impress в режиме показа слайдов, чтобы гиперссылки работали по клику.

## Пересборка

```bash
python3 scripts/build_epd_quiz.py
```

## Таймер и ответ

В режиме показа слайдов на каждом вопросе крутится обратный отсчёт 30→0. Карточка «Ответ» скрыта и появляется по анимации ровно через 30 секунд.

## Красные ячейки после открытия

В режиме показа слайдов PowerPoint запоминает открытые гиперссылки: номер в ячейке становится **красным**, когда вы возвращаетесь на поле кнопкой «К полю».

Это стандартный механизм «followed hyperlink» (как в классических Jeopardy-шаблонах).

Дополнительно в папке есть `QuizMacros.bas` — макросы, которые красят **заливку** ячейки в красный (для сохранения как `.pptm`).
