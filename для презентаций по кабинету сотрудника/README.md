# Презентации по «1С:Кабинет сотрудника»

## Преддемонстрация сервиса (15 слайдов)

Файл: [`1С_Кабинет_сотрудника_Преддемонстрация.pptx`](./1С_Кабинет_сотрудника_Преддемонстрация.pptx)

Сценарий для менеджера перед демонстрацией: о компании → проблема → ценность КЭДО → выгоды по ролям → факты об экономии → приглашение к демо.

### Структура

1. Титульный  
2. О группе компаний «Форус» (forus.ru/about)  
3. Почему компании переходят на КЭДО  
4. Что такое 1С:Кабинет сотрудника  
5. Что умеет сервис  
6. Почему нравится сотрудникам  
7. Что получает кадровик  
8. Что получает бухгалтер  
9. Что получает руководитель  
10. Что получает ИТ-специалист  
11. Сравнение с другими решениями *(ориентировочное — проверить перед публикацией)*  
12. Экономический эффект  
13. Как проходит внедрение  
14. Что покажем на демонстрации  
15. Обсудим ваши процессы (открытый вопрос)

### Источники цифр и формулировок

- [forus.ru](https://www.forus.ru/) и [О компании](https://www.forus.ru/about/) — факты о ГК Форус  
- [1С:Кабинет сотрудника](https://www.forus.ru/produkty-1c/servisy/1c-kabinet-sotrudnika/) — возможности, тарифы, кейсы, ИТ-преимущества  
- Листовка «Кабинет сотрудника» / «КС для ЦКС» — до 70% экономии времени, от 21 ₽/мес. на сотрудника, более 5000 клиентов, тарифы  
- Excel «Экономия при переходе на КЭДО» — расчёт экономии на бумаге и времени  
- Презентация после Мастерской по КС (июнь 2026) — боли, аргументы по ролям, вопросы клиенту  
- «Первая встреча с заказчиком» — описание сервиса и скриншоты

Шаблоны Форус, PDF/PPTX с контентом, регламенты, расчёт экономии.
