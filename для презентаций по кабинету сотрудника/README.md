# Презентации по «1С:Кабинет сотрудника»

## Преддемонстрация сервиса (14 слайдов)

Файл: [`1С_Кабинет_сотрудника_Преддемонстрация.pptx`](./1С_Кабинет_сотрудника_Преддемонстрация.pptx)

Сценарий для менеджера перед демонстрацией: проблема → ценность КЭДО → выгоды по ролям → факты об экономии → приглашение к демо.

### Структура

1. Титульный  
2. Почему компании переходят на КЭДО  
3. Что такое 1С:Кабинет сотрудника  
4. Что умеет сервис  
5. Почему нравится сотрудникам  
6. Что получает кадровик  
7. Что получает бухгалтер  
8. Что получает руководитель  
9. Что получает ИТ-специалист  
10. Сравнение с другими решениями *(ориентировочное — проверить перед публикацией)*  
11. Экономический эффект  
12. Как проходит внедрение  
13. Что покажем на демонстрации  
14. Обсудим ваши процессы (открытый вопрос)

### Источники цифр и формулировок

- Листовка «Кабинет сотрудника» / «КС для ЦКС» — до 70% экономии времени, от 21 ₽/мес. на сотрудника, более 5000 клиентов, тарифы  
- Excel «Экономия при переходе на КЭДО» — расчёт экономии на бумаге и времени  
- Презентация после Мастерской по КС (июнь 2026) — боли, аргументы по ролям, вопросы клиенту  
- «Первая встреча с заказчиком» — описание сервиса и скриншоты  

### Исходные материалы в этой папке

Шаблоны Форус, PDF/PPTX с контентом, регламенты, расчёт экономии.

### Пересборка

```bash
python3 scripts/build_kedo_presentation.py
```

Требуется: `python-pptx`, шаблон Форус и иконки в `presentation/assets/`.
