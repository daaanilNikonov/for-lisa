# Заявки с теста

Хранение ответов — в Яндекс.Форме:
https://forms.yandex.ru/u/6a83b54feb614605f98e10ee

Лендинг собирает имя / телефон / ИНН в своей форме. **Должность (пункт 4)**
подставляется из ответа на 1-й вопрос квиза и уходит в Яндекс.Форму вместе
с остальными полями (через предзаполненный iframe).

Дополнительно заявка пишется в `localStorage` браузера (выгрузка CSV в админке).

Таблица-заготовка в репозитории: `submissions.csv`.
