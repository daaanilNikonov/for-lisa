# Заявки с теста

Таблица: `submissions.csv`

После отправки анкеты на лендинге заявка:
1. уходит в Яндекс.Форму (если указан URL в `scripts-data.js` → `yandexForm.url`);
2. сохраняется в браузере и может быть выгружена в CSV;
3. при выгрузке «Скачать заявки CSV» — допишите строки в этот файл и закоммитьте.

Поля: дата, имя, телефон, ИНН, id сценария, название сценария, КЭДО, источник.
