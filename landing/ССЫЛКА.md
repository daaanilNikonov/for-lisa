# Лендинг с тестом

## Папка в GitHub

https://github.com/daaanilNikonov/for-lisa/tree/cursor/quiz-landing-scripts-55dd/лендинг%20тест

## Открыть лендинг в браузере

https://htmlpreview.github.io/?https://github.com/daaanilNikonov/for-lisa/blob/cursor/quiz-landing-scripts-55dd/лендинг%20тест/index.html

Или локально: откройте `ОТКРЫТЬ ЛЕНДИНГ.html` / `index.html`.

```bash
cd "лендинг тест"
python3 -m http.server 8080
```

http://localhost:8080

## Окно загрузки картинок и текстов

На странице лендинга: секция **«Загрузить контент»**  
прямая ссылка с якорем: `.../index.html#editor`
