# Вставка лендинга в Тильду

Два готовых варианта — копируйте содержимое файла в блок **«HTML-код» (T123)**.

## 1. iframe (рекомендуется)

Файл: `1-iframe-dlya-tildy.html`

- Вся логика в отдельной странице, Тильда не ломает стили
- Откройте файл → скопируйте код → вставьте в HTML-блок
- При желании замените `src` iframe на URL вашего VDS

## 2. HTML-код одной страницы

Файл: `2-html-kod-dlya-tildy.html`

- Квиз встраивается прямо в страницу Тильды
- CSS / JS / картинки подгружаются с CDN автоматически
- Файл `2-html-kod-polnaya-stranica.html` — полная HTML-страница (для проверки в браузере)

## Как вставить в Тильду

1. Страница на поддомене → **Добавить блок** → **Другое** → **HTML-код**
2. Вставить код из файла
3. В настройках блока убрать лишние отступы / сделать на всю ширину
4. Опубликовать

Если после публикации стили «поехали» — используйте вариант **iframe**.
