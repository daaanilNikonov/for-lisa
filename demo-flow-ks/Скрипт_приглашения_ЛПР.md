# Шпаргалка: приглашение на демо с несколькими ЛПР

## Название встречи
Рабочая сессия: кадровые процессы компании — где теряем время и как ускорить в контуре 1С

## Кому писать / звонить
Не только кадровику. В копию или в список участников:
- руководитель / собственник
- финдиректор / тот, кто утверждает бюджет
- главбух / руководитель кадров
- ИТ (если чувствительна тема безопасности)

## Текст (короткий)

Предлагаем 35–45 минут рабочей сессии по кадровому контуру — не лекцию про софт.

До встречи (5 минут) — экспресс-профиль из 7 вопросов. По ответам покажем только ваши сценарии: расчётки, отпуска, согласования, удалёнка, КЭДО.

С нашей стороны: менеджер + специалист по «1С:Кабинет сотрудника».
С вашей: лучше 2–4 человека, влияющих на решение.

## Если говорят «придёт только бухгалтер»
Ок для разбора процессов. Для решения по бюджету и срокам позовём руководителя хотя бы на финальные 15 минут — покажем эффект и риски.
