# Шпаргалка: как пригласить на демонстрацию нескольких людей, принимающих решение

## Название встречи
Рабочая сессия: кадровые процессы компании — где теряем время и как ускорить в контуре 1С

## Кому писать / звонить
Не только кадровику. В копию или в список участников:
- руководитель / собственник
- финансовый директор / тот, кто утверждает бюджет
- главный бухгалтер / руководитель кадров
- ИТ (если важна тема безопасности)

## Текст (короткий)

Предлагаем 35–45 минут рабочей сессии по кадровым процессам — не лекцию про программу.

До встречи (5 минут) — экспресс-профиль из 7 вопросов. По ответам покажем только ваши сценарии: расчётные листки, отпуска, согласования, удалёнку, кадровый электронный документооборот.

С нашей стороны: менеджер по продажам + специалист по «1С:Кабинет сотрудника».
С вашей: лучше 2–4 человека, которые влияют на решение.

## Если говорят «придёт только бухгалтер»
Для разбора процессов — нормально. Для решения по бюджету и срокам позовём руководителя хотя бы на последние 15 минут — покажем эффект и риски.
