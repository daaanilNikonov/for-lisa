# Редактируемый макет опросника для Figma

## Что это
Набор **SVG-экранов**. Их можно импортировать в Figma — фигуры и текст станут редактируемыми слоями (не одной картинкой).

## Как открыть в Figma
1. Скачайте папку `figma-editable-svg` или архив `maket-oprosnik-figma-editable.zip`
2. Откройте Figma → создайте файл
3. Перетащите SVG-файлы на холст **или** меню: `File → Import` / `Place image`
4. Каждый экран станет фреймом со слоями: прямоугольники, текст, кнопки
5. При необходимости сгруппируйте слои в Frame (`Ctrl/Cmd + Alt + G`)

## Важно
- Это не нативный `.fig`-файл (его Figma наружу почти не отдаёт для генерации).
- SVG — самый надёжный способ получить **изменяемый** макет без плагинов.
- Шрифт в SVG указан как Inter / Segoe UI / Arial. В Figma можно заменить на фирменный.
