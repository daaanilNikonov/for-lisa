# Как открыть редактируемый макет в Figma

Файл: `Макет_опросник_Кабинет_сотрудника.sketch`

Это настоящий дизайн-макет (формат Sketch). Figma умеет импортировать его как **редактируемые фреймы и слои** (текст, кнопки, карточки — отдельно).

## Шаги
1. Скачайте файл `.sketch`
2. Откройте Figma → **File → Import file…** (или перетащите файл в окно Figma / браузерную вкладку файлов)
3. Дождитесь импорта
4. Откроется страница с экранами опросника: старт, 7 вопросов, результат

Если Import не виден: на домашней странице Figma нажмите **Import** рядом с New design file.
