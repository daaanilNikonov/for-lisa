# Как открыть редактируемый макет в Figma

Файл: `Макет_опросник_Кабинет_сотрудника.sketch`

Фирменный стиль Форус: белый + жёлтый `#FECF68`, текст `#395F75`.

## Важно
В макете используется шрифт **Inter** (есть кириллица). Раньше текст мог не отображаться из‑за Helvetica без кириллицы — это исправлено.

## Шаги
1. Скачайте `.sketch`
2. Figma → **File → Import file…** (или Import на домашней странице)
3. Откройте импортированный файл
4. На странице — экраны: старт, 7 вопросов с текстом, результат

Если шрифт подсвечен как missing — замените на Inter в Figma (он встроен).
