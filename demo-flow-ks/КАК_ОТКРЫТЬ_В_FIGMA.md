# Макет опросника Форус для Figma

## Файл (новый, бело-жёлтый)
`Опросник_Форус_желтый_макет.sketch`

Внутри уже «вшиты» экраны с:
- логотипом Форус
- жёлтым корпоративным стилем (#FECF68)
- текстами всех 7 вопросов
- корпоративными значками внизу

## Как открыть
1. Скачайте файл заново (имя другое — чтобы не подтянулся старый кэш)
2. Figma → **Import file…**
3. Откройте импортированный файл

Текст и стиль будут видны сразу, потому что экраны встроены в макет как готовые артборды.
