# Демонстрация «1С:Кабинет сотрудника»

## С чего начать
1. Откройте подробный гайд: `Гайд_новый_сценарий_демо_КС.md`  
   Там живым языком расписаны этапы, роли, фразы и план после встречи.
2. Откройте карту: `Демо_1С_Кабинет_сотрудника_карта.xmind`  
   5 листов — схема, как привести ЛПР, вопросы, три сценария, финал и метрики.

## Остальные файлы
- `Матрица_вопросы_блоки_демо.csv` — ответ → действие
- `Анализ_эффективности_и_улучшения.md` — продуктовая логика
- `Опросник_Форус_желтый_макет.sketch` — макет опросника для Figma

## Сценарии демонстрации по аудиту (PDF)

`Сценарии_демонстрации_по_аудиту_Кабинет_сотрудника.pdf` — подробное описание шести сценариев демо (С1–С6) на основе вопросов сайта аудита кадровых процессов.

Источник логики выбора сценариев: ветка `cursor/audit-landing-55dd` (файл `audit-landing/scripts-data.js`).
