# Обновлённый формат демонстрации «1С:Кабинет сотрудника»

Материалы в этой папке описывают новый сценарий демо: сначала **экспресс-профиль кадровых процессов** (квалификация + сбор потребности), затем короткая демонстрация **только по ответам клиента**, в финале — менеджер по продажам.

## Файлы

| Файл | Назначение |
|------|------------|
| `Демо_1С_Кабинет_сотрудника_карта.xmind` | Блок-схема / mind map (4 листа) |
| `Гайд_новый_сценарий_демо_КС.md` | Полный гайд: вопросы, маппинг, скрипт приглашения, опросник |
| `Матрица_вопросы_блоки_демо.csv` | Таблица «ответ → блок демо» для специалиста |

## Листы в XMind

1. **Новый сценарий демо КС** — общий поток от приглашения до закрытия сделки  
2. **Карта вопросов → блоки демо** — 7 вопросов с ветками ответов  
3. **Библиотека блоков демо** — конструктор сценария для специалиста  
4. **Заход для ЛПР + опросник** — как собрать несколько ЛПР и чем сделать квиз  

Открывать в [XMind](https://xmind.app/) (Zen / 2020+).
