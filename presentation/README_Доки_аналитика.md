# Презентация: аналитика проекта «Доки»

Защита пилота продаж и передача в тиражирование другой группе.

## Файл

- [`Доки_Аналитика_защита_и_тиражирование.pptx`](./Доки_Аналитика_защита_и_тиражирование.pptx) — готовая презентация (14 слайдов)
- Фирменный стиль: тёмный шаблон **ГК Форус** (`Презентация ГК Форус темный шаблон 16х9 (1).pptx` в корне репозитория)

## Структура слайдов

1. Титульный  
2. Зачем запускали проект  
3. Ключевые цифры за 7 недель  
4. Гипотеза 1 — Доки по базе ЭПД вместо 1С-ЭПД (9 продаж)  
5. Гипотеза 2 — Доки в скрипте связки (9 продаж)  
6. Сравнение двух гипотез  
7. **Выгода для показателей: ЭДО + ЭПД** (одна сделка закрывает два KPI)  
8. Что уже готово к передаче  
9. **Как использовать материалы** (схема для новой группы)  
10. Оффер (3 месяца безлимит бесплатно)  
11. Выводы по проекту  
12. Рекомендации для тиражирования  
13. Каких данных не хватает для полной защиты  
14. Просим принять решение  

## Цифры пилота (зафиксированы в презентации)

| Показатель | Значение |
|---|---|
| Срок | 7 недель |
| Гипотез проверено | 2 |
| Подключений всего | 18 |
| Гипотеза 1 (база ЭПД → Доки) | 9 продаж |
| Гипотеза 2 (скрипт КабС–Доки–Смартвей–Доки.Логистика) | 9 продаж |
| Оффер | 3 месяца безлимит бесплатно |
| Вклад в KPI | ЭДО (Доки) + ЭПД (Доки.Логистика) |

## Пересборка

```bash
python3 scripts/build_doki_analytics_presentation.py
```

Требуется: `python-pptx`, `lxml`, исходный шаблон Форус в корне, иконки в `presentation/assets/icons`.

Добавить на слайды 3 / 6 / 11 / 13:

1. **Воронка** — касания → демо → продажи по каждой гипотезе
