# Презентация: аналитика проекта «Доки»

Защита пилота продаж и передача в тиражирование другой группе.

## Файл

- [`Доки_Аналитика_защита_и_тиражирование.pptx`](./Доки_Аналитика_защита_и_тиражирование.pptx) — готовая презентация (17 слайдов)
- Фирменный стиль: тёмный шаблон **ГК Форус**

## Структура слайдов

1. Титульный  
2. Зачем запускали проект  
3. Ключевые цифры  
4. Обработка: сколько звонили (1 084 + база ЭПД 311)  
5. Воронка и менеджеры  
6. Показатели по базам (+ база ЭПД = 316)  
7. Гипотеза 1 — база ЭПД (9 продаж)  
8. Гипотеза 2 — скрипт связки (9 продаж)  
9. Сравнение двух гипотез  
10. Выгода для показателей: ЭДО + ЭПД  
11. Что уже готово к передаче  
12. Как использовать материалы  
13. Оффер (3 месяца безлимит)  
14. Выводы  
15. Рекомендации для тиражирования  
16. Каких данных не хватает  
17. Просим принять решение
