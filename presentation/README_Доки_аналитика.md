# Презентация: аналитика проекта «Доки»

Защита пилота продаж и передача в тиражирование другой группе.

## Файл

- [`Доки_Аналитика_защита_и_тиражирование.pptx`](./Доки_Аналитика_защита_и_тиражирование.pptx) — готовая презентация (12 слайдов)
- Фирменный стиль: тёмный шаблон **ГК Форус** (`Презентация ГК Форус темный шаблон 16х9 (1).pptx` в корне репозитория)

## Структура слайдов

1. Титульный  
2. Зачем запускали проект  
3. Ключевые цифры за 7 недель  
4. Гипотеза 1 — Доки вместо 1С-ЭПД (9 продаж)  
5. Гипотеза 2 — Доки в скрипте связки (9 продаж)  
6. Сравнение двух гипотез  
7. Что уже готово к передаче  
8. Оффер (3 месяца безлимит бесплатно)  
9. Выводы по проекту  
10. Рекомендации для тиражирования  
11. Каких данных не хватает для полной защиты  
12. Просим принять решение  

## Цифры пилота (зафиксированы в презентации)

| Показатель | Значение |
|---|---|
| Срок | 7 недель |
| Гипотез проверено | 2 |
| Подключений всего | 18 |
| Гипотеза 1 (база ЭПД → Доки) | 9 продаж |
| Гипотеза 2 (скрипт КабС–Доки–Смартвей–Доки.Логистика) | 9 продаж |
| Оффер | 3 месяца безлимит бесплатно |

## Пересборка

```bash
python3 scripts/build_doki_analytics_presentation.py
```

Требуется: `python-pptx`, `lxml`, исходный шаблон Форус в корне, иконки в `presentation/assets/icons`.

## Данные, которые усилят защиту (если появятся)

Добавить на слайды 3 / 6 / 9 / 11:

1. **Воронка** — касания → демо → продажи по каждой гипотезе  
2. **Размер базы** — сколько контактов обработали по ЭПД-каналу и по скрипту  
3. **Деньги** — средний чек / выручка сейчас / план после пробного периода  
4. **Активность** — сколько из 18 реально пользуются сервисом  
5. **Отказы** — типовые причины «нет»  
6. **Ресурсы** — трудозатраты пилота и владелец сопровождения после передачи
