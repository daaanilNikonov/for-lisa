# Стратегическая сессия по ЭПД

Презентация для стратегической сессии по направлению ЭПД в жёлто-белом корпоративном стиле ГК Форус.

## Файл

- [`Стратегическая_сессия_ЭПД.pptx`](./Стратегическая_сессия_ЭПД.pptx)

## Структура (8 слайдов)

1. Титульный — Стратегическая сессия по ЭПД  
2. Повестка сессии  
3. Поле «время взятия в работу» заявки с РК  
4. Разделение стоимости РК между ЦП и ЦКС (встреча 27.08)  
5. Продление РК и согласование бюджета  
6. ОС от МПП: проблемы, возражения, потребности  
7. Портрет клиента, который купил ЭПД  
8. Финансовая модель направления ЭПД  

## Пересборка

```bash
python3 scripts/build_epd_strategy_session.py
```

Требуется: `python-pptx`, `Pillow` (для декоративных элементов).
