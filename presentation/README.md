# Презентации по «1С:Кабинет сотрудника»

## Статус работы группы запуска (жёлто-белый стиль Форус)

Файл: [`Статус_Кабинет_сотрудника_август_2026.pptx`](./Статус_Кабинет_сотрудника_август_2026.pptx)

10 слайдов 16×9, корпоративный шафран Форус (`#FECF68`) на белом — без тёмно-синего шаблона.

### Структура

1. Титульный  
2. О чём этот отчёт  
3. О проекте  
4. Как устроена работа  
5. План проекта: все задачи выполнены  
6. Четыре гипотезы простыми словами  
7. Анализ звонков: воронка и вклад менеджеров  
8. Анализ звонков: показатели по базам  
9. Почему отказываются после демонстрации  
10. На чём держим внимание  

Цифры воронки: период 23.07–24.08.2026, свод трёх листов КС (Юлиана, Соня, Данил).  
План закрыт по документу «План проекта Кабинет сотрудника».  
Причины отказа после показа — из мастерской по Кабинету сотрудника (июнь 2026) и разбора встреч.

### Пересборка

```bash
python3 scripts/build_ks_status_presentation.py
```

Нужен `python-pptx`. Логотип и волны — в `presentation/assets/brand/`.
