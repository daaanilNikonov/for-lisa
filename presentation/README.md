# Презентации по «1С:Кабинет сотрудника»

## Статус работы группы запуска (жёлто-белый стиль Форус)

Файл: [`Статус_Кабинет_сотрудника_август_2026.pptx`](./Статус_Кабинет_сотрудника_август_2026.pptx)

12 слайдов 16×9, корпоративный шафран Форус (`#FECF68`) на белом — без тёмно-синего шаблона.

### Структура

1. Титульный  
2. Содержание  
3. Описание проекта  
4. Карта проекта (четыре контура + карта дня)  
5. Что уже сделано из материалов  
6. Четыре гипотезы — обзор  
7. H1 ИТС ПРОФ и H4 семинары (свои клиенты)  
8. H2 ОКВЭД и H3 связка ДОКИ + КЭДО (холод)  
9. Воронка и вклад менеджеров  
10. Показатели по базам из «КС аналитика»  
11. Кейсы демонстраций — пустые карточки под заполнение  
12. Что усиливаем дальше  

Цифры воронки: период 23.07–24.08.2026, свод трёх листов КС (Юлиана, Соня, Данил).

### Пересборка

```bash
python3 scripts/build_ks_status_presentation.py
```

Нужен `python-pptx`. Логотип и волны — в `presentation/assets/brand/`.
