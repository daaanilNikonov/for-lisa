# Презентация: продвижение «1С:Кабинет сотрудника»

Пилотная презентация (7 слайдов) для согласования запуска проекта по стратегии «Благодарность + Спецпредложение» среди топ-клиентов в Иркутске.

## Файл

- [`Продвижение_1С_Кабинет_сотрудника.pptx`](./Продвижение_1С_Кабинет_сотрудника.pptx) — готовая презентация
- Фирменный стиль: тёмный шаблон **ГК Форус** (`Презентация ГК Форус темный шаблон 16х9 (1).pptx` в корне репозитория)

## Структура слайдов

1. Титульный  
2. Актуальность: почему сейчас  
3. Решение: план действий (3 шага)  
4. Результативность: выгоды для клиента и KPI  
5. Финансовая смета (37 000 ₽)  
6. Дорожная карта по этапам  
7. Заключение и запрос на одобрение  

## Пересборка

```bash
# иконки из шаблона (прозрачный фон) уже лежат в presentation/assets/icons
python3 scripts/build_presentation.py
```

Требуется: `python-pptx`, исходный шаблон Форус в корне репозитория.
