Карта дня · Форус — загрузка на домен
=====================================

Что в архиве
------------
Папка karta-dnya/ — готовое Node.js-приложение (чеклисты, план недели, KPI, PDF-отчёт).
Нужен Node.js 18+ на сервере. Обычный «статический» хостинг (только HTML) не подойдёт.

Вариант A. VPS / сервер с Node.js (рекомендуется)
-------------------------------------------------
1. Распакуйте архив на сервер, например в:
   /var/www/karta-dnya
   или в каталог сайта: public_html/karta-dnya

2. Установите зависимости:
   cd karta-dnya
   npm ci
   (если npm ci нет — npm install)

3. Запуск:
   ./start.sh
   или: PORT=3847 npm start

   Приложение:
   http://ВАШ-ДОМЕН:3847/karta-dnya
   http://127.0.0.1:3847/karta-dnya

4. Без порта в URL (https://ВАШ-ДОМЕН/karta-dnya) — nginx reverse proxy.
   Проще всего: поддомен karta.ВАШ-ДОМЕН → proxy на 127.0.0.1:3847
   Пример: deploy/nginx-karta-dnya.conf.example

5. Автозапуск: deploy/karta-dnya.service.example
   или: npm i -g pm2 && pm2 start server.js --name karta-dnya && pm2 save

Вариант B. Панель хостинга с Node.js (Beget / Timeweb / REG.RU)
--------------------------------------------------------------
1. Загрузите ZIP в файловый менеджер и распакуйте.
2. В настройках Node.js-приложения:
   - entry: server.js
   - start: npm start
   - Node.js ≥ 18
3. Выполните npm install в каталоге приложения.
4. Откройте https://ВАШ-ДОМЕН/.../karta-dnya (путь приложения — /karta-dnya).

--------------------------
