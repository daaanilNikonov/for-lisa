# Документы отдела продуктового запуска

## Карта компетенций и ожиданий

Файл: [`Карта_компетенций_менеджер_продуктовый_запуск.docx`](./Карта_компетенций_менеджер_продуктовый_запуск.docx)

Шаблон для индивидуального анализа менеджера по продажам (отдел продуктового запуска):

- поле **Сотрудник** и метаданные оценки сверху;
- блок **Действие** ↔ **Корпоративные компетенции** ↔ **Как у сотрудника в реальности**;
- блок **Ожидания по работе** ↔ **Корпоративные компетенции** ↔ **Реальность**;
- итог, зоны роста и подписи.

Оформление в корпоративном стиле ГК Форус (фирменный жёлтый `#FCCD68`, шрифт Verdana).

### Пересборка

```bash
python3 scripts/build_competency_map.py
```

Требуется: `python-docx`.


## Должностная инструкция тимлида

Файл: [`Должностная_инструкция_тимлид_продуктовый_запуск.docx`](./Должностная_инструкция_тимлид_продуктовый_запуск.docx)

Должностная инструкция Тимлида группы продуктового запуска на основе карты функций/компетенций (зона Лизы), с усилением блоков:

- продуктовая разработка;
- взаимодействие со смежными отделами;
- контроль и обучение МПП.

Пересборка:

```bash
python3 scripts/build_teamlead_job_description.py
```
