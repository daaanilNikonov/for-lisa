## Что внутри

- 7–8 вопросов (после «есть КЭДО» — вопрос «Каким КЭДО вы пользуетесь?» + поле ввода)
- 10 сценариев по триггерам, название зависит от должности (кадровик-любимчик / бухгалтер-любимчик…)
- Кнопка «Узнать, как усилить процессы» → форма (имя, телефон, ИНН)
- Кнопка «Поделиться результатами» → скриншот + ссылка
