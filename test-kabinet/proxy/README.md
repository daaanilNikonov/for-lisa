# Прокси Яндекс.Формы (опционально)

Основной путь на лендинге — синхронизация полей в iframe Яндекс.Формы
(должность из 1-го вопроса подставляется автоматически).

`server.mjs` — запасной серверный `POST /api/yandex-submit`.
С датацентровых IP Яндекс часто показывает капчу, поэтому на проде
лучше опираться на iframe-мост в `app.js`.

```bash
node test-kabinet/proxy/server.mjs
```
