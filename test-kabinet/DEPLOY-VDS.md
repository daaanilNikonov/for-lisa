# Выгрузка на VDS

1. Распакуйте архив в каталог веб-сервера (nginx/apache), например `/var/www/test-kabinet/`.
2. Корень сайта или location должен указывать на папку с `index.html`.
3. Откройте `https://ваш-домен/` — всё работает на относительных путях, без CDN.

Опционально (серверная отправка в Яндекс.Форму):
```bash
node proxy/server.mjs
```
и в `scripts-data.js` укажите `proxyUrl: "/api/yandex-submit"`.
Без этого заявки уходят через iframe Яндекс.Формы прямо из браузера.
