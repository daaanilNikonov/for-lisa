# Как привязать Google Form к аудиту

Лендинг сам **не может тихо отправить** ответ в Google без вашей формы:
браузер блокирует прямую отправку (CORS). Поэтому схема такая:

1. На лендинге клиент заполняет ФИО / телефон / ИНН / компанию.
2. По кнопке «Отправить заявку» открывается **ваша Google Form** уже с
   предзаполненными полями + кодом сценария (С1…С6) и текстом аудита.
3. Клиент (или менеджер) нажимает «Отправить» уже в Google Form.
4. Параллельно заявка сохраняется в браузере (`localStorage`) на всякий случай.

---

## Шаг 1. Создайте форму

1. Откройте [Google Forms](https://forms.google.com/).
2. Создайте новую форму, например: **«Заявки — Аудит Кабинет сотрудника»**.
3. Добавьте поля (тип «Короткий текст» / «Абзац»):

| Поле на форме | Тип | Зачем |
|---|---|---|
| ФИО | Короткий текст | Имя клиента |
| Телефон | Короткий текст | Контакт |
| ИНН | Короткий текст | ИНН |
| Компания | Короткий текст | Название |
| Код сценария | Короткий текст | С1…С6 для демо |
| Аудит | Абзац | Список находок |

Можно добавить служебные поля (дата, комментарий менеджера) — лендинг их не трогает.

4. В правом верхнем углу нажмите **Отправить** (иконка самолётика) → вкладка **ссылка**.
5. Скопируйте обычную ссылку вида:
   `https://docs.google.com/forms/d/e/1FAIpQL…/viewform`

---

## Шаг 2. Узнайте `entry.XXXX` для каждого поля

Нужны технические id полей — без них предзаполнение не работает.

1. В той же форме снова **Отправить** → **ссылка**.
2. Включите **«Получить ссылку для предзаполнения»** / *Get pre-filled link*
   (в интерфейсе: «предзаполненная форма» / pre-filled link).
3. Откроется форма — **впишите тестовые значения** в каждое поле
   (например: `Тест`, `79001234567`, `7707083893`, `ООО Ромашка`, `С3`, `Не согласуются отпуска`).
4. Нажмите **«Получить ссылку»**.
5. Скопируйте длинный URL. В нём будут параметры вида:

```text
.../viewform?usp=pp_url&entry.123456789=Тест&entry.987654321=79001234567&entry.111222333=С3&...
```

6. Выпишите соответствие:

```text
ФИО            → entry.123456789
Телефон        → entry.987654321
ИНН            → entry.555666777
Компания       → entry.444333222
Код сценария   → entry.111222333
Аудит          → entry.999888777
```

Цифры у вас будут другие — берите **свои** из ссылки.

---

## Шаг 3. Пропишите это в лендинге

Откройте файл `audit-landing/scripts-data.js` и найдите блок `googleForm`.

Замените заглушки на свои значения:

```js
googleForm: {
  url: "https://docs.google.com/forms/d/e/1FAIpQL....../viewform",
  fields: {
    name: "entry.123456789",
    phone: "entry.987654321",
    inn: "entry.555666777",
    company: "entry.444333222",
    scenario: "entry.111222333",
    audit: "entry.999888777",
  },
},
```

Важно:
- `url` — именно `/viewform` (не `/formResponse`).
- `entry.*` — **без** `=` и без значений, только id.
- Пока в файле остаётся `REPLACE_…`, лендинг считает форму неподключённой.

Сохраните файл, залейте на хостинг (или обновите `forus-audit-landing.zip`).

---

## Шаг 4. Проверка

1. Откройте лендинг, пройдите 10 вопросов до аудита.
2. Нажмите **«Оставить заявку на демо»**.
3. Заполните ФИО, телефон, ИНН.
4. Нажмите **«Отправить заявку»** — должна открыться Google Form
   уже с заполненными полями и кодом вроде `С3`.
5. В Google Form нажмите **Отправить**.
6. В ответах формы (вкладка «Ответы») появится новая строка.

Кнопка **«Открыть Google Form»** делает то же самое без повторного ввода на лендинге.

---

## Частые ошибки

| Симптом | Причина | Что сделать |
|---|---|---|
| Открывается пустая форма | Неверные `entry.*` или перепутаны поля | Заново снимите pre-filled link |
| «Форма не подключена» в подсказке | В файле ещё `REPLACE_FORM_ID` / `REPLACE_NAME` | Замените все REPLACE_ |
| Поля на русском, а в URL кракозябры | Это нормально (URL-encode) | Ничего, Google сам декодирует |
| Нужна отправка без второго клика | Google так не даёт с чужого сайта | Оставьте схему «предзаполнение + Отправить» |

---

## Куда смотреть ответы

Google Form → вкладка **«Ответы»** → можно связать с Google Таблицей
(иконка таблицы) — тогда каждая заявка будет строкой с кодом сценария С1–С6.
