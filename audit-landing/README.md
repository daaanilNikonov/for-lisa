# Аудит кадровых процессов · ГК Форус

Лендинг-опрос без картинок в корпоративном бело-жёлтом стиле.

## Что делает

1. 10 вопросов по расчётным листкам, справкам, отпускам, командировкам и документам.
2. В конце — **аудит** (список находок). Пример: ответ «фиксируем согласование отпуска никак» → «Не согласуются отпуска…».
3. Код сценария демо: **С1–С6** (для изменения сценария демонстрации).
4. Анкета клиента → Google Form (предзаполнение) + локальное сохранение в браузере.

## Коды сценариев

| Код | Когда | Фокус демо |
|-----|--------|------------|
| С3 | Отпуск не фиксируется / устно | Заявление и согласование отпуска |
| С4 | Справки вручную и часто | Самообслуживание справок |
| С5 | Есть командировки | Командировки + документы |
| С6 | Поиск через HR / бумажный архив | Личный кабинет документов |
| С1 | Уже многое в 1С | Расширение единого контура |
| С2 | Смешанный контур (по умолчанию) | Полный путь сотрудника |

## Подключение Google Form

Подробная пошаговая инструкция: **[GOOGLE-FORM.md](./GOOGLE-FORM.md)**.

1. Создайте форму с полями: ФИО, телефон, ИНН, компания, код сценария, аудит.
2. «Отправить» → ссылка с предзаполнением → скопируйте `entry.XXXX` из URL.
3. Впишите в `scripts-data.js` → `googleForm.url` и `googleForm.fields`.

Пока стоят `REPLACE_*`, заявка сохраняется локально (`localStorage`), код сценария копируется кнопкой.

## Запуск

Откройте `index.html` локально или выложите папку `audit-landing/` на хостинг целиком.

Архив: `dist/forus-audit-landing.zip`
