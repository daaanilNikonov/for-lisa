# Данные для инвестиционной модели «Кабинет сотрудника»

## Файлы

- `sschr_fns_2025.json` — ИНН → [ССЧР, ДатаСост] из открытых данных ФНС (`7707329152-sshr2019`, данные за 2025).
- `okved_egrul.json` — ИНН → основной/доп. ОКВЭД из выписок ЕГРЮЛ (приоритетный сегмент 22+).
- `client_inns.json` — уникальные ИНН клиентской базы.
- `model_stats.json` — сводные счётчики после последней сборки.

## Пересборка модели

```bash
python3 scripts/build_investment_model.py
```

Результат: `Финансовый_план_Кабинет_сотрудника_ИНВЕСТИЦИОННАЯ_МОДЕЛЬ.xlsx`

## Обогащение ОКВЭД (актуально)

Источники по приоритету:
1. **РСМП ФНС** (`7707329152-rsmp`) — основной ОКВЭД для субъектов МСП.
2. **ЕГРЮЛ/ЕГРИП** (`egrul.nalog.ru`) — для организаций вне реестра МСП (крупный бизнес, бюджетные учреждения).
3. Дополнительно: ранее собранный кэш выписок.

Целевые префиксы ОКВЭД (ICP): 45–47, 10–33, 41–43, 49, 52, 55–56, 68, 78, 80–82, 64–66, 61–63, 85, 86.
Лист модели `05a_Целевая_база_ОКВЭД` — уникальные ИНН с целевым ОКВЭД.
